# Wedding Planner Design System

Premium, editorial, calm, consumer-friendly design language.

## Structure

- `tokens.ts` - Design token definitions
- `theme.css` - CSS custom properties
- UI components live in `src/components/ui/` (shadcn/ui: Button, Input, Label, Card, etc.)

## Principles

- Serif display font for headlines
- Clean sans serif for UI text
- Soft neutrals with one accent color
- Generous spacing
- Rounded panels, subtle shadows
